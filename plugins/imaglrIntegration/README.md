# Imaglr Integration

Share images and clips from Stash to your [imaglr](https://imaglr.com) blogs as drafts, queued posts or
published posts.

Full documentation (requirements, setup, use, exactly what it changes in Stash and on imaglr, limitations):
https://github.com/SentientSlimeMould/stash-imaglr-integration#readme

- Tag images or scene markers `imaglr` in Stash, or use **⋯ → Add to imaglr** in any image list.
- Open **imaglr** in the main menu to edit and send them. Add your imaglr blog's API key under **Settings** first.
