# Security

This plugin stores imaglr API keys and sends your media to imaglr, so problems in that area matter more than
ordinary bugs.

**Please report anything that could expose a key, send something you didn't choose to send, or change your Stash
library in a way the README doesn't describe** privately, using GitHub's
[private vulnerability reporting](https://github.com/SentientSlimeMould/stash-imaglr-integration/security/advisories/new)
rather than a public issue. You'll get a reply within a few days; fixes are released through the normal plugin
update so every install gets them.

Everything else — crashes, wrong behaviour, feature requests — belongs on the
[issue tracker](https://github.com/SentientSlimeMould/stash-imaglr-integration/issues). When you attach Stash
log lines, the plugin masks imaglr keys and Stash's own key in its messages, but do check before pasting.

What the plugin does and doesn't do with your data is described in the README under **What the plugin changes**.
